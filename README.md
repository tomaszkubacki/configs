# Minimal machine provision configuration

Install just command runner from snap repository

```shell
sudo snap install just
```


## install

copy entire repo to your home dir

```shell
cp -rf * ~/
```


## repos structure

**just** - contains all just commands splitted into modules
.config - contains various config files
